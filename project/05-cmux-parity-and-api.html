cmux Parity and API Plan

RemoteCode 2 should look and behave like cmux, then add Agent App APIs. Public terms: window, workspace, pane, surface.

Parity Matrix

cmux capabilityRemoteCode 2 V1 targetNotes
Native macOS Swift/AppKit appRequiredCore rewrite requirement.
Vertical workspaces/sidebarRequiredWorkspace rows show cwd, git branch, notifications, active agent state, and port metadata when a detector exists; otherwise show a typed unavailable state.
Horizontal surface tabs inside panesRequiredSurfaces include terminal, browser, agentApp.
Split panesRequiredSplit right/down and directional focus are core workflows.
Ghostty terminalRequired if license path allowsUse cmux-style libghostty. Fallback must meet terminal pass criteria before V1.
WKWebView browserRequiredMust support navigation, profiles, local dev use, and automation subset.
Browser automationP0 required, P1 plannedUse cmux agent-browser-port spec priorities.
Socket/CLI automationRequiredcmux-compatible command families plus agent extensions.
Notifications and unread routingRequiredAgent completion/attention should light workspace/surface like cmux.
Session restoreRequiredAdd Agent App snapshots to cmux-style snapshot tree.
SSH/remote daemon/cloud VMDefer unless explicitly requiredKeep API placeholders only if needed for future parity.
Markdown/file preview/right sidebar toolsDefer until after coreNot central to requested RemoteCode value. Document if omitted from V1.

CLI Surface

CommandContract
remotecode2 new-workspace --cwd PATH --name NAMECreate workspace.
remotecode2 new-surface --type terminal|browser|agentCreate a surface in the current or target pane.
remotecode2 new-split right --type agentSplit current pane and create Agent App surface.
remotecode2 browser ...Mirror cmux browser command family where implemented.
remotecode2 agent openOpen/focus Agent App surface.
remotecode2 agent send --text TEXT --provider codex|claudeCreate or use selected thread and start run.
remotecode2 notifySend workspace/surface notification.

Surface Creation Rules

Input typeResult
terminalCreate terminal surface with workspace cwd, shell env, and RemoteCode context variables.
browserCreate browser surface. Optional url navigates after creation.
agent or agentAppCreate Agent App surface bound to workspace/project. Optional provider/thread fields select initial state.

Deferred Compatibility

If RemoteCode 2 cannot directly reuse cmux code because of licensing, the V1 target remains behavioral parity, not source-level parity. Every deferred cmux command must return a clear unsupported error and appear in release notes.
