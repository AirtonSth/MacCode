Agent App Surface Spec

The Agent App is the main RemoteCode differentiator: cmux surfaces plus a native graphical Codex/Claude app surface.

Surface Contract

AgentAppSurface is a normal surface inside a pane. It can be created, closed, focused, moved, split, restored, renamed, marked unread, and controlled by CLI/socket commands. It does not own the whole window. Terminal and browser surfaces remain sibling tools.

protocol AgentProviderRunner {
    var provider: AgentProvider { get }
    func listModels() async throws -> [AgentModelDescriptor]
    func startRun(_ request: AgentRunRequest) async throws -> AgentRunHandle
    func stopRun(_ runID: UUID) async
    func resumeThread(_ providerThreadID: String, request: AgentRunRequest) async throws -> AgentRunHandle

enum AgentProvider: String, Codable {
    case codex
    case claude
}

Important UX Rules

  • Provider selection locks once a thread has provider thread history, unless the user creates a new thread.
  • Codex and Claude expose the same timeline UI even if their raw event formats differ.
  • Agent App should offer one-click "Open Terminal Right" and "Open Browser Right" because that is the core cmux workflow.
  • When an agent needs attention, workspace and surface unread indicators follow cmux notification behavior.
  • Stopping a run should produce a durable cancelled state, not leave the thread marked running after restart.
