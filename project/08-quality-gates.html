Quality Gates

Tests must verify intent, not just behavior. Gates are written as product invariants.

Test Layers

LayerScopeRequired examples
UnitPure Swift domain logic.Provider parsers, event normalization, migration mapping, snapshot encode/decode, command parameter validation.
IntegrationSQLite, process runners, socket server, browser automation.Codex/Claude fixture streams, SQLite migrations, JSON-RPC commands, WKWebView eval/screenshot.
UISwiftUI/AppKit behavior.Workspace selection, split creation, surface switching, Agent App send/stop, timeline virtualization, keyboard focus.
End-to-endReal app launched as signed/dev build.Create workspace, split terminal/browser/agent, run fake provider, session restore, CLI automation.
PerformanceMeasured budgets.Cold launch, memory, terminal scrollback, browser creation, Agent App streaming under long output.

Intent-Focused Tests

RiskIntent test
Provider switch corrupts thread historyA thread with existing provider thread ID locks provider selection because provider-native resume IDs are not interchangeable.
Cancelled run looks active after restartStopping a run records cancellation and app restart does not resume it as running.
Agent App is not a real surfaceCLI can move/split/focus/close Agent App exactly like terminal and browser.
Migration drops data silentlyFixture with bad rows imports valid rows and reports every skipped row with reason.
Browser automation targets wrong surfaceTwo browser surfaces exist; command with surface ID affects only the target.
Terminal focus steals Agent App inputSwitching from terminal to Agent App routes text input to composer, not shell.

Release Blockers

  • Block if cmux license path is unresolved and cmux source was copied.
  • Block if migration can lose messages or provider thread IDs silently.
  • Block if Agent App cannot be created as a normal surface through CLI/socket.
  • Block if app restart can duplicate provider runs.
  • Block if signed app cannot launch on a clean macOS account.
