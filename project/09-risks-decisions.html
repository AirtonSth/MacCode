Non-Negotiable Constraints

  • All source, docs, tests, and commit messages must be English.
  • Desktop UI must run inside native macOS chrome. No fake titlebar/window buttons.
  • Final desktop app cannot depend on the old Electrobun runtime.
  • Agent App must support both Codex and Claude, not only Codex.
  • Each screen should load only data required for the visible screen. Lazy-load secondary panels.
  • Live Activity delivery, if retained, must use direct APNS, not Firebase/FCM.
