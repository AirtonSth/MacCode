Surface Protocol

Every surface needs identity, type, title, icon, focus, close, session snapshot, and automation hooks. Agent App should not be a special root view. It must satisfy the same surface contract as terminal and browser.

enum SurfaceType: String, Codable {
    case terminal
    case browser
    case agentApp
}

@MainActor
protocol Surface: ObservableObject, Identifiable where ID == UUID {
    var id: UUID { get }
    var type: SurfaceType { get }
    var title: String { get }
    var iconName: String { get }
    var isDirty: Bool { get }
    var hasUnreadActivity: Bool { get }

    func focus(_ intent: SurfaceFocusIntent?)
    func unfocus()
    func close()
    func makeSessionSnapshot() -> SurfaceSnapshot
}

Architectural Constraints

  • The final app must not require a local HTTP backend to render its own UI.
  • Socket automation is for external control, not internal UI state sync.
  • Provider-specific logic must stay below AgentProviderRunner. UI consumes normalized events only.
  • Terminal/browser/agent surfaces must be movable, splittable, restorable, and closeable through the same API.
  • Any cmux code reuse is blocked until license path is decided: GPL-compatible project or commercial license.
