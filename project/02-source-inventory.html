Architecture Facts To Preserve

  • RemoteCode has one unified assistant event model for Codex and Claude. Keep that model.
  • cmux public terminology should win: window, workspace, pane, surface. Avoid exposing internal "panel" language in new APIs except compatibility.
  • Agent App is a new surface type, not a new app mode or side panel.
  • Terminal and browser are not embedded inside Agent App. They are sibling surfaces in the cmux layout.
  • Current RemoteCode desktop UI state should migrate into native SQLite models, not remain as JSON blobs unless explicitly marked compatibility-only.
