Things you should know to use it safely

  • State directory: ~/Library/Application Support/RemoteCode2Debug/. Channels isolated. Override via RC2_APP_SUPPORT, RC2_DB_PATH, RC2_CHANNEL.
  • Unix socket: /tmp/RemoteCode2{Debug,Canary}.sock, mode 0600. Local-only.
  • HTTP server: binds 127.0.0.1:18217 by default. Flip settings.remote_access_enabled = "1" to bind 0.0.0.0; pairing required to issue tokens; tokens validated on every /v1/* non-loopback request.
  • Codex / Claude CLI must be in PATH; missing binary surfaces as an explicit "not found in PATH" error.
  • Session restore: the layout tree is restored exactly; each Surface is created fresh (new shell pid, new web page). Agent runs that were active during a crash get marked interrupted and never auto-resume.
  • The minimal CommonMark subset in MarkdownSurface covers headings/bold/italic/code/lists/links/hr. Tables, footnotes, GFM extensions are not implemented.
  • Browser P1 automation uses a WeakMap of refs created by browser.snapshot. Subsequent browser.click etc. expect the most recent snapshot's refs.
