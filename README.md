# RemoteCode.io

![Mobile UI](https://raw.githubusercontent.com/samuelfaj/remotecode.io/main/hero.gif)

**Code anywhere. Continue everywhere.**

RemoteCode.io lets developers continue their local AI coding sessions (Claude Code or Cursor) directly from their mobile devices.

A lightweight server runs on your computer (macOS, Windows, or Linux) and securely streams your active coding sessions to a native iOS or Android app. Your repositories never leave your machine. Your AI tools keep running locally. Your phone becomes a remote control for your coding workflow.

## Features

- **Secure Local Streaming**: Your coding sessions stay on your machine with end-to-end encryption.
- **AI Tool Support**: Compatible with Claude Code, Cursor, and other local AI coding assistants.
- **Cross-Platform**: Desktop server for macOS, Windows, and Linux; mobile apps for iOS and Android.
- **No Cloud Required**: Everything runs locally, ensuring privacy and security.
- **Seamless Sync**: Continue your session seamlessly between devices.

## How It Works

1. Install and run the desktop app on your computer.
2. Install the mobile app on your iOS or Android device.
3. Open the desktop app and start your coding session with your preferred AI tool.
4. Use the mobile app to remotely control and continue coding.

Everything syncs in real-time between your PC and phone, so you're free to move around while keeping your AI coding session active.

## Installation

**Don't want to configure anything?** Visit [https://remotecode.io/](https://remotecode.io/) to download the pre-built apps and get started instantly!

### Desktop App

- **Download**: Get the latest release from [https://remotecode.io/](https://remotecode.io/).
- **Build from Source**: Clone the repo and follow the build instructions in `desktop/README.md`.

### Mobile App

- **iOS**: Download from the [App Store](https://remotecode.io).
- **Android**: Download from [Google Play](https://remotecode.io/).

## Usage

1. Launch the RemoteCode desktop app on your computer.
2. Ensure your AI coding tool (e.g., Claude Code) is installed.
3. Open the RemoteCode mobile app on your device.
4. Connect the mobile app to the desktop server (usually automatic via local network or login).
5. Start coding remotely!
